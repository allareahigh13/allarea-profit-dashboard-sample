# 経営ダッシュボード（デザイン見本）

売上・原価・利益と、現場・商談・タスク・メモを見る、複数ページの経営ダッシュボードの見本です。
数字・名前は、すべて**合成のサンプル**（`data.sample.json`）です。本物の情報は入っていません。

- ページ：ホーム／タスク／案件管理（案件の一覧・商談記録）／現場進捗状況（全案件のガントチャート・工程表・日報と写真）／職人の確認ページ／見積もり作成／メモ／売上分析（現場ごとの収支）／損益分析（全事業・リフォーム事業・人材紹介業）／活動分析／担当者別／目標・予実／レポート／AI分析
- 損益の単位は万円、案件・見積は円です。利益 ＝ 売上 − 原価（資材費 ＋ 人件費）。
- 音声データの取り込みは、サンプルの受信箱で流れを再現しています（クラウド録音サービスとは、つないでいません）。
- 編集内容は、このブラウザにだけ保存されます。写真は、このブラウザ（IndexedDB）に縮小して保存されます。
- 現場の詳細の工程表に、資材の発注の期限（着工の前日 −届くまでの日数）のマーク・「発注するもの」の一覧・発注済みのチェック・期限が近いときのアラートがあります。タスクは、大項目の中に小項目を足してチェックすると進み具合（%）が変わり、メモも書けます。
- タスクの追加は、右下のタスクの画面の「＋」から、「人に頼む」か「自分のタスクを追加する」かを選べます（小項目も足せます）。
- ホーム上部の「今日やること」（押して対応でき、原因・対応・AIにできることが見える）、分析期間（単月／直近3か月／年累計）の統一、グラフの見直し（円グラフの視認性・利益の累計線・原価の内訳）、ガントチャートの詳細と動きと要確認マーク、レポート（週間・月次・四半期・年間と、アドバイザーの意見）があります。数字はすべて合成です。
- 操作マニュアル（manual.html）：全ページの場所・操作・色と記号・用語・よくある質問。左メニュー最下段と各ページ上のリンクから開けます。
- 色味は、画面上の丸いボタンで4種類に切り替えられます。
- 計算の試験：`node --test tests/calc.test.mjs`
