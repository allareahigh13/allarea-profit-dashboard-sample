# 経営ダッシュボード（デザイン見本）

売上・原価（資材費と人件費）・利益と、目標に対する進捗を見る、複数ページの経営ダッシュボードの見本です。
数字はすべて**合成のサンプル**（`data.sample.json`）で、本物の数字は入っていません。

- ページ：ホーム／案件管理／現場進捗状況（工程表つき）／見積もり作成／売上分析／損益分析（全事業・リフォーム事業・人材紹介業）／活動分析／担当者別／目標・予実／レポート／AI分析
- 損益の単位は万円、案件管理・見積は円です。利益 ＝ 売上 − 原価（資材費 ＋ 人件費）。
- 案件・工程・見積の編集内容は、このブラウザにだけ保存されます。
- 色味は、画面上の丸いボタンで4種類に切り替えられます。
- 計算の試験：`node --test tests/calc.test.mjs`
